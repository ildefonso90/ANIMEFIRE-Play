# AnimeFire Player

Extensao Manifest V3 para abrir paginas do AnimeFire em uma janela propria com lista de episodios na mesma ordem da pagina do anime.

## Como instalar no Chrome ou Edge

1. Abra `chrome://extensions` ou `edge://extensions`.
2. Ative o modo de desenvolvedor.
3. Clique em `Carregar sem compactacao`.
4. Selecione esta pasta: `D:\PROJECTOS\ESTENsâo`.

## Como usar

1. Acesse `https://animefire.io`.
2. Abra uma pagina de anime ou episodio.
3. Clique no botao flutuante `Abrir player`.

O player le a lista de episodios da pagina `todos-os-episodios`, usa a rota normal de video do proprio site e nao baixa arquivos. A permissao para `lightspeedst.net` e usada apenas para carregar a midia que o AnimeFire retorna.
